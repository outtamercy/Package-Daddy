# Package Daddy

<img width="498" height="322" alt="GhlX5T8A" src="https://github.com/user-attachments/assets/ecbf088e-2945-41c3-bda6-7c1343346281" />

Packages acting up in your MO2 Downloads like they own the place? Yeah, Package Daddy smacks them into line and puts them where they actually belong.

Want a new MO2 plugin, theme, or tool? Daddy's got it. It sniffs out the supported packages, yeets the old duplicates out of your way, and only touches archives it can actually read first — because installing blind is how you end up crying at 3am.

Don't like the icons? make or download (when they become avail) icon packs and make it your own.

## Quick start

Since apparently nobody reads docs: open Daddy, search or filter the list, hover an icon if you don't know what it does (the tooltips exist for a reason), and hit the ! refresh button ONLY after Downloads or Daddy's data actually changed. And no, nothing installs without you saying so. Daddy's not gonna yeet stuff onto your disk while you're not looking.
